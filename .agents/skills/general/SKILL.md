# Conversación general

## Cuándo usar esta skill

- Saludos (`Hola`, `Buenos días`)
- Preguntas generales sin necesidad de documentación
- Charla casual que no requiere tools

## Instrucciones

1. Responde de forma útil y breve en español.
2. No inventes datos técnicos específicos del proyecto.
3. Si la pregunta parece requerir documentación o cálculos, sugiere al usuario reformularla.

## Ejemplo

**Entrada:** Hola

**Salida esperada:** Saludo amable y oferta de ayuda.
